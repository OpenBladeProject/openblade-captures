# Инструменты записи USB-трафика OpenBlade

[English](README.md) | [简体中文](README.zh-CN.md) | Русский

В этом репозитории находятся инструменты Windows и проверенные данные протоколов для исследования интерфейсов прошивки Razer Blade. Отдельный репозиторий для записей обмена помогает не включать исходные данные в выпуски продукта.

Начните с [руководства по записи трафика](docs/ru-RU/CAPTURE_GUIDE.md). В нём описано исследование ещё не поддерживаемой модели Blade: инвентаризация устройства, изолированная запись трафика, контрольное чтение, восстановление, очистка данных и допуск в основную поддержку.

Установленные пакеты драйверов Razer учитываются в [`blade-driver-catalog`](https://github.com/OpenBladeProject/blade-driver-catalog/blob/main/README.ru-RU.md). Используйте тот репозиторий для инвентаризации и экспорта пакетов. Этот репозиторий хранит записи обмена по протоколу и результаты физических проверок, по которым определяется, поддерживает ли пакет конкретную возможность устройства.

Общая документация OpenBlade находится в [`OpenBladeProject/openblade-docs`](https://github.com/OpenBladeProject/openblade-docs/blob/main/README.ru-RU.md).

<a id="before-you-start"></a>
## Перед началом работы

- Храните исходные файлы PCAP и PCAPNG только локально.
- Не добавляйте в Git серийные номера, имена пользователей, локальные пути, суффиксы экземпляров устройств и непроверенные потоки данных команд.
- Записывайте одно действие оператора за сеанс и исследуйте запросы чтения до команд записи.
- Не используйте команду от другой модели Blade без записи обмена и проверки на точной целевой модели.

[Руководство по записи трафика](docs/ru-RU/CAPTURE_GUIDE.md) содержит полные правила безопасности, команды, справочник инструментов, порядок подготовки доказательств и контрольный список допуска.

<a id="repository-layout"></a>
## Структура репозитория

- `annotations`: действия оператора, происхождение данных, время и результаты проверок безопасности.
- `decoded`: очищенные тестовые данные запросов и ответов, покрытие и анализ.
- `plans`: проверенные планы интерактивной валидации с контролем точных байтов.
- `raw`: локальные файлы PCAP, игнорируемые Git. В репозиторий добавлен только `.gitkeep`.
- `templates`: версионированные исходные документы для новых исследований.
- `tests`: синтетические автономные регрессионные тесты без доступа к реальному оборудованию.
- `tools`: скрипты захвата, декодирования, сравнения, очистки и проверки.
